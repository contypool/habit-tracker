# Трекер привычек

## Цель

Создать простой учебный трекер привычек.

## Пользователь проекта

Проект предназначен для новичка в программировании, поэтому код и объяснения должны быть простыми и понятными.

## Технологии

- HTML
- CSS
- JavaScript без фреймворков

## Основные функции

- Добавление привычки.
- Отметка привычки как выполненной.
- Удаление привычки.
- Сохранение данных в браузере.

## Интерфейс

Интерфейс должен корректно и удобно работать как на компьютере, так и на телефоне.
