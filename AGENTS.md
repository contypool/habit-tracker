# Правила работы над проектом

Проект учебный, а его пользователь — новичок в программировании. Во время работы соблюдай следующие правила:

- Объясняй каждое изменение простыми и понятными словами.
- Выполняй только один небольшой этап за раз.
- Не устанавливай библиотеки без разрешения пользователя.
- Не удаляй файлы без разрешения пользователя.
- После каждого изменения сообщай, как проверить результат.
- Если нужно изменить несколько файлов, сначала покажи короткий план.
